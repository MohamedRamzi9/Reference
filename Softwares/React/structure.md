This file should describe the structure of a React application, all but only the necessary files and folders for the application to run properly, what each file and folder is for


- **node_modules/** : this folder contains all the dependencies and packages that are installed via npm (Node Package Manager). It is automatically generated when you run `npm install` and should not be modified manually.
- **package.json** : this file contains metadata about the project, including the name, version, scripts, and modules required for the application. can be used to reinstall dependencies by running `npm install`.
- **index.js** : this is the entry point of the React application where the rendering starts
